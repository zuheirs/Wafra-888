# وفرة 888 — منصة الماسترمايند (خادم حقيقي)

هاد إعادة بناء كاملة للنموذج الأولي (`wafra888mastermind.html`) بخادم حقيقي:
مصادقة من طرف الخادم بكلمات سر مُشفّرة (hashed)، قاعدة بيانات حقيقية، ونداءات
الذكاء الاصطناعي كلها من الخادم (مفتاح الـ API ما بينكشف أبداً بالمتصفح — كانت
هاي أخطر ثغرة بالنموذج الأولي).

## ليش Flask/Python وليس Next.js/Supabase؟

البريف اقترح Next.js + Supabase + Vercel كبنية تقنية. لكن بيئة البناء يلي اشتغلت
فيها ما كانت قادرة تحمّل حزم npm أو pip جديدة إطلاقاً (سياسة شبكة على مستوى
البيئة). عشان هيك بنيت النظام بـ **Flask (Python)** لأنه كان المتوفر فعلياً
بالبيئة، وقدرت أشغّله وأختبره بالكامل هون (اختبار آلي شامل بـ `smoke_test.py`
يغطي كل تدفقات العمل: تسجيل دخول، تغيير كلمة سر، حفظ بروفايل، محادثة، استخراج
أنماط، طلبات DCA، حضور وقفل تلقائي، إلخ) بدل ما أكتب كود Next.js ما بقدر
أشغّله ولا أتأكد منه.

النتيجة نفس المتطلبات الوظيفية بالضبط (قسم 4 بالبريف) بس بستضافة مختلفة —
أي host بيدعم Python (Render، Railway، Fly.io، أو حتى VPS عادي) بدل Vercel.
قاعدة البيانات SQLite افتراضياً (صفر إعداد) وقابلة للتبديل لـ Postgres حقيقي
(مثلاً Supabase) بمجرد ضبط `DATABASE_URL` — راجع تحت.

## 1) التشغيل المحلي (تجربة سريعة)

```bash
cd wafra888
python3 -m venv .venv && source .venv/bin/activate   # اختياري بس موصى فيه
pip install -r requirements.txt

cp .env.example .env
# افتح .env واملأ على الأقل: SECRET_KEY و ANTHROPIC_API_KEY

python3 seed.py     # يزرع الحسابات الاثنا عشر (SQLite تلقائياً)
python3 run.py       # يشتغل على http://localhost:5000
```

كلمة السر الابتدائية لكل الحسابات: **0000** — والنظام بيجبر تغييرها أول دخول.

للتأكد إن كل شي شغّال صح بدون ما تحتاج مفتاح API حقيقي:
```bash
python3 smoke_test.py
```
هاد بيعمل محاكاة (mock) لنداءات Anthropic ويختبر ~23 سيناريو فعلي (دخول خاطئ،
CSRF، حفظ بروفايل، محادثة، قفل تلقائي عند غياب بدون اعتذار، موافقة القيادة على
طلب DCA...). لازم يطلع "ALL SMOKE TESTS PASSED".

## 2) النشر الحقيقي (خطوة بخطوة)

### أ) قاعدة البيانات
**خيار سريع (SQLite):** ما تحتاج تعمل شي — بس تأكد إن الاستضافة يلي رح تختارها
عندها قرص دائم (persistent disk) لأن SQLite ملف واحد، مو مناسب لاستضافة "بدون
حالة" زي بعض إعدادات Vercel/Netlify المجانية.

**خيار Postgres حقيقي (مثلاً Supabase، متل ما اقترح البريف):**
1. سوّي مشروع مجاني على [supabase.com](https://supabase.com)
2. من SQL Editor، شغّل محتوى `migrations/postgres_schema.sql` كامل مرة وحدة
3. من Project Settings → Database → Connection string (URI)، انسخ الرابط
4. حطه بـ `DATABASE_URL` بملف `.env`
5. شيل التعليق عن `psycopg[binary]` بملف `requirements.txt` وثبّتها: `pip install -r requirements.txt`

### ب) مفتاح Anthropic API
سجّل بـ [console.anthropic.com](https://console.anthropic.com)، ولّد مفتاح،
حطه بـ `ANTHROPIC_API_KEY`. راجع
[docs.claude.com/en/docs/about-claude/models](https://docs.claude.com/en/docs/about-claude/models)
للتأكد من اسم الموديل الأحدث وقت النشر الفعلي وحطه بـ `ANTHROPIC_MODEL`.

### ج) الإيميل التلقائي (اختياري لكن موصى فيه)
سجّل بـ [resend.com](https://resend.com) (مجاني لحجم صغير)، ولّد API key،
حطه بـ `RESEND_API_KEY`، وحط إيميلات القيادة بـ `LEADERSHIP_EMAILS`
(مفصولة بفاصلة). لو تركته فاضي، كل شي بيشتغل عادي بس بدون إيميلات — التنبيهات
بتضل تظهر بلوحة القيادة.

### د) الاستضافة (أي واحدة من هدول، كلهم عندهم free tier)
**Render** (الأسهل):
1. ارفع المجلد كامل (ما عدا `.env` و `*.db`) على GitHub
2. سوّي "New Web Service" على render.com واربطه بالـ repo
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn wsgi:app --bind 0.0.0.0:$PORT`
5. ضيف كل متغيرات `.env` بـ Environment Variables بلوحة Render
6. لو مستخدم SQLite: فعّل "Persistent Disk" واربطه بمسار وحط `SQLITE_PATH` عليه

**Railway / Fly.io**: نفس الفكرة — `pip install -r requirements.txt` ثم
`gunicorn wsgi:app --bind 0.0.0.0:$PORT`.

بعد أول نشر، شغّل مرة وحدة (من شل الاستضافة أو محلياً بنفس `DATABASE_URL`):
```bash
python3 seed.py
```

### هـ) الفحص الدوري التلقائي (cron)
Flask نفسه ما عنده جدولة مدمجة. اربط أي خدمة cron مجانية (مثلاً
[cron-job.org](https://cron-job.org) أو GitHub Actions scheduled workflow)
تستدعي مرة بالأسبوع:
```
GET https://your-domain.com/cron/weekly-check?token=CRON_SECRET_يلي_حطيته_بـ_env
```
هاد بيفحص مين لسا ما قدّم الفورم أو عنده حساب معلّق، ويبعت إيميل ملخّص للقيادة
(لو Resend مضبوط).

### و) تفعيل كـ تطبيق موبايل (PWA)
ما في حاجة لأي إعداد إضافي — الموقع جاهز كـ PWA (`manifest.json` +
`service worker` + أيقونات). أي عضو يفتح الرابط بمتصفحه، ويضغط "إضافة للشاشة
الرئيسية" (Add to Home Screen)، وبتصير عنده أيقونة تفتح متل تطبيق عادي، مجاناً
وبدون أي مراجعة من أي متجر.

## 4) الفروقات الأمنية عن النموذج الأولي (الإصلاحات المطلوبة بالبريف)

- **كلمات السر:** مُشفّرة بـ pbkdf2-sha256 مع salt (`werkzeug.security`)، مو نص
  صريح بالكود ولا بأي مكان يشوفه المتصفح.
- **التحقق من الهوية:** بالكامل من طرف الخادم (`/login` POST)، مو JavaScript
  بالمتصفح.
- **مفتاح Anthropic API:** موجود بس بمتغيرات بيئة الخادم، ما بينبعث للمتصفح
  إطلاقاً — كل محادثة بتمر عبر `/api/chat/send` و `/api/leadership/chat/send`.
- **CSRF:** توكن ينولّد وقت الدخول، ولازم ينبعث بكل طلب يغيّر حالة (POST).
- **قفل بعد محاولات دخول خاطئة متكررة:** 6 محاولات → قفل 10 دقائق.
- **جلسات موقّعة (signed cookies)** مع `SECRET_KEY` سري، `HttpOnly`،
  و`Secure` بالإنتاج (يتطلب HTTPS).

**ملاحظة أمانة (متل ما طلب البريف بالضبط):** عزل المحادثة الخاصة عن القيادة
هو تعليمات صارمة بالـ system prompt يتبعها النموذج، وليس قفل تقني حاسم متل
التشفير. القيادة ما بتقدر توصل لمحتوى المحادثة أبداً من الواجهة أو الـ API
(محجوب فعلياً بالكود، مو بس بالتعليمات)، لكن استخراج الأنماط نفسه بيعتمد على
التزام النموذج اللغوي بالقواعد المعطاة له.

## 5) قرارات هندسية تستاهل انتباهك

- **حذف الحساب "نهائي":** نفّذته كـ soft delete (الحساب ينحظر من الدخول
  والبيانات بتضل موجودة للسجل والتدقيق) بدل حذف فعلي من قاعدة البيانات — أأمن
  وقابل للتراجع. لو بدك حذف فعلي، سهل نضيفه.
- **التذكير بالواتساب:** ما في حل آلي مجاني بهالحجم (متل ما البريف حدد)،
  فأضفت حقل رقم هاتف اختياري لكل عضو (تضيفه القيادة من لوحة "تذكيرات") ورابط
  `wa.me` جاهز بنص جاهز — بس الإرسال يدوي دايماً.
- **"تقرير المسافة عن الرؤية":** البريف حدد إنها مرحلة قادمة مش أساسية للإطلاق
  الأول. محادثة القيادة الحرة والتقرير التحليلي الحاليين موجّهين أصلاً لتركيز
  على "وين المجموعة ككل بطريق تحقيق الرؤية" مش بس التزام فردي — بس مقياس جماعي
  رسمي ومنظم (متل "كم عضو حوّل نوره لمشروع ملموس") لسا محتاج تصميم إضافي معك
  قبل ما نبنيه صح.
- **الـ Postgres path (اتصال Supabase) انكتب وما انختبر فعلياً هون** لأن مكتبة
  psycopg ما كانت متوفرة ببيئة البناء (نفس قيد الشبكة). الكود مبني بعناية على
  نفس نمط SQLite المختبر بالكامل، لكن جرّبه بحساب Supabase تجريبي قبل ما تعتمد
  عليه بالإنتاج.
